# Sanitär Bebbi – Website-Entwurf

Design-Entwurf einer neuen Website für **Sanitär & Heizung BEBBI**, Müllheimerstrasse 36, 4057 Basel.
Layout nach der Framer-Vorlage [Plumbzo](https://plumbzo.framer.website/), Akzentfarbe im Bebbi-Blau, Texte auf Deutsch (Schweiz).

> Unverbindlicher Vorschlag, keine offizielle Seite des Betriebs. Die Seite ist für Suchmaschinen gesperrt (`noindex`).

## Aufbau

Eine einzige statische Seite ohne Build-Schritt:

```
index.html   Seite inkl. CSS und JavaScript
img/         Fotos und Logo
```

Lokal ansehen: `index.html` im Browser öffnen.

## Vor dem Livegang

- Hinweis «Design-Entwurf» (`.draft`) und `<meta name="robots" content="noindex,nofollow">` entfernen
- Kontaktformular mit einem Versanddienst oder dem Bebbi-Postfach verbinden (aktuell nur Vorschau-Hinweis)
- Impressum und Datenschutzerklärung ergänzen
- Header-Foto idealerweise durch ein Foto aus dem Bebbi-Team ersetzen

## Bildnachweis

- Projektfotos und Logo: Sanitär Bebbi (sanitaer-bebbi.ch)
- Übrige Fotos: Pexels, Unsplash und Pixabay (jeweils kostenlos, auch kommerziell nutzbar)
